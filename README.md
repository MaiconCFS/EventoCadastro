# Sistema de Cadastro para Eventos

Sistema desenvolvido para gerenciamento de eventos e participantes. Trabalho desenvolvido para disciplina de programação de soluções computacionais.

## Descrição
Sistema em Java para cadastro e gerenciamento de eventos, permitindo:
- Cadastro de eventos
- Inscrição de participantes
- Controle de dados persistentes
- Diferentes tipos de eventos

## Funcionalidades
- Cadastro de eventos
- Inscrição de participantes
- Persistência em arquivos
- Diferentes tipos de evento
- Formatação de datas

## Como Executar
```bash
# Compilar o projeto
javac -d bin src/**/*.java

# Executar a aplicação
java -cp bin main.AgendaEventosApp
